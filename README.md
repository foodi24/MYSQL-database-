# MYSQL-database-
# 📌 SQL Database with HTML Forms

This project demonstrates how to create and connect an SQL database to a website using **InfinityFree** as the hosting provider and **HTML Forms** for user input. The HTML form was created using concepts and examples from **W3Schools**, while the database was hosted and managed through InfinityFree.

---

# 🎯 Project Objectives

* Create a free SQL database using InfinityFree.
* Design an HTML form for user data entry.
* Connect the HTML form to the SQL database.
* Store submitted data successfully in the database.
* Demonstrate the interaction between a web form and a database.

# 🚀 How It Works

1. Create a MySQL database on InfinityFree.
2. Design an HTML form using W3Schools examples.
3. Connect the website to the database using PHP.
4. Submit data through the form.
5. Store the submitted information in the SQL database.
